## 3. 个体经验 / 踩坑

- 2026-11-13 [已验证] **冒烟脚本失败先分清"实现 bug"还是"测试写法错"**：本轮最后一次失败表面是"dedup 未记录"，真因是流式 ack 用了已取消的 stream ctx + CLI 不按 correlation 过滤 + payload_ref 被填成 job_id 三个实现 bug。只改断言会掩盖真问题 —— 证据: 修后冒烟与崩溃演练全绿；适用: 任何端到端脚本红灯。
- 2026-11-13 [已验证] 断言"不得含某子串"前先想清楚编码往返：JSON `<` 解码就是 `<`，用 `Contains(c,"<")` 断言"未转义"永远失败（本轮反复踩 5 次）。改断言精确等于期望串 —— 证据: `hub/config/canonical_test.go`；适用: 序列化/转义类断言。
- 2026-11-13 [已验证] 真库集成测试的隔离粒度要按"测试并行单元"选：`go test ./...` 并行跑**包**，所以按包分 database（不是分 schema，因为测试 SQL 用 `kernel.` 显式限定名）。夹具清理必须覆盖所有被用例改写的种子字段，否则随机顺序失败 —— 证据: `internal/pgtest`、本轮 `bots.enabled` 与 `kernel_secret_refs` 两次污染。
- 2026-11-13 [已验证] 装不上的工具链不要硬等：`buf@latest` 拉 go1.26.11 卡住、并发安装争抢 module-cache 锁（22 分钟仅 7s CPU）。改用缓存里已有的 `protocompile` 写离线生成器（`GOPROXY=off`）当场产出，生成物提交入库 —— 证据: 本轮 proto 生成成功；适用: 工具链缺失但产物可提交时。
- 2026-11-13 [已验证] 新增 RPC 需用户确认时，优先用"入口适配器复用同一模块"绕过契约改动：M1 用 hub HTTP 网关承载 user_bot 侧入口，proto 七个 RPC 一字未改，校验与审计仍走同一 ingress —— 证据: 详设 §10.1 第 1 条；适用: 契约冻结期的功能落地。
