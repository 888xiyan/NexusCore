## MVP 交付形态（一句话）

一个 hub 单二进制（含 9 模块）+ 一个 bot-runtime 二进制 + 一个 MySQL 实例（金库库 / 记忆库双 schema、双凭据），跑通"信封入口 → 队列 → lazy Bot → Agent 短连接 → 蒸馏回包 → Outbox 事件"全链路。
