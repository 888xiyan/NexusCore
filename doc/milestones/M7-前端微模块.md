# M7 详细设计定版：前端微模块化与插件注册表体系（Plugin Registry）

> **文档状态**：正式定版归档（Approved & Finalized）  
> **版本标识**：NexusCore v0.1.0 模块化基石  
> **定版日期**：2026-11-15  
> **核心主题**：基于**方案 A（Vite ESM 原生动态导入 + 运行时共享底座）**，将前端工作台重构为“纯净宿主壳（Host Shell）+ 插件注册中心（Plugin Registry）+ 业务插件自治微模块”的无缝解耦微前端架构。

---

## 1. 架构目标与设计原则

在 M4～M6 的快速迭代中，多 Bot 群聊（M4）、本地 Agent 探针监视（M5）与 Bot 蓝图工厂（M6）均直接硬编码在前端单体页面 `WorkbenchView.vue` 中，导致：
1. 宿主与插件业务边界模糊，新增业务页面需修改宿主核心代码；
2. 缺乏动态路由挂载与侧边栏动态装配能力；
3. 无法支持第三方插件独立提供前端 UI 扩展。

**M7 的核心任务是彻底完成前端微模块化解耦：**
1. **纯净宿主壳（Host Shell）**：`Frontend/` 仅提供应用全局布局（Header 顶部栏、自适应动态 Sidebar、工作台視区 `<router-view>`）、全局通知与 SSE 事件桥接，**100% 剥离业务页面代码**；
2. **零冗余运行时共享（Zero-Redundancy Runtime Sharing）**：宿主全局暴露 `window.__NEXUS_CORE__`（共享 Vue 3、Pinia、Vue Router、Element Plus 实例），避免 iframe 割裂与子包体积膨胀；
3. **插件注册中心（PluginRegistry）**：向插件提供标准注册上下文 `NexusUIContext`，支持动态路由挂载（`registerRoute`）、动态侧边栏装配（`registerMenu`）、扩展插槽挂载（`registerSlotComponent`）与全局事件监听；
4. **业务视区插件化自治**：
   - `plugin_groupchat`（群聊协同工作台）：独立微模块，注册 `/groupchat` 路由；
   - `plugin_agent_discovery`（本地 Agent 资产与探针监控）：独立微模块，注册 `/agents` 路由；
   - `plugin_bot_creator`（Bot 蓝图工厂与 200 行记忆向导）：独立微模块，注册 `/bot-factory` 路由。

## 3. 契约接口规范（`src/types/nexus-ui.ts`）

### 3.1 宿主注册上下文（`NexusUIContext`）

```typescript
export interface NexusUIContext {
  // 1. 动态路由注入
  registerRoute(route: {
    path: string;
    name: string;
    component: any;
    meta?: Record<string, any>;
  }): void;

  // 2. 侧边栏菜单注册（支持动态图标与未读数回调）
  registerMenu(menu: {
    id: string;
    title: string;
    icon: string;
    path: string;
    order?: number;
    badge?: () => number | string | undefined;
  }): void;

  // 3. 全局插槽组件注册
  registerSlotComponent(
    slotName: 'header_status' | 'header_actions' | 'sidebar_footer' | 'workbench_widget',
    component: any
  ): void;

  // 4. 全局总线与事件广播
  bus: {
    on(event: string, handler: (payload: any) => void): void;
    off(event: string, handler: (payload: any) => void): void;
    emit(event: string, payload: any): void;
  };

  // 5. 统一消息轻提示
  notify: {
    success(msg: string): void;
    warning(msg: string): void;
    error(msg: string): void;
    info(msg: string): void;
  };
}
```

### 3.2 插件微模块导出契约（`NexusPluginUI`）

```typescript
export interface NexusPluginUI {
  id: string;
  name: string;
  version: string;
  install(ctx: NexusUIContext): void | Promise<void>;
  uninstall?(ctx: NexusUIContext): void;
}
```

## 4. 插件清单 `manifest.json` UI 扩展定义

各业务插件在其 `manifest.json` 中增加标准 `"ui"` 节点：

```json
{
  "plugin_id": "plugin_groupchat",
  "name": "GroupChat Plugin",
  "ui": {
    "menu": {
      "title": "群聊协同工作台",
      "icon": "ChatDotRound",
      "path": "/groupchat",
      "order": 1
    },
    "routes": [
      {
        "path": "/groupchat",
        "name": "GroupChatWorkspace",
        "entry": "/plugins/groupchat/dist/index.js"
      }
    ]
  }
}
```
