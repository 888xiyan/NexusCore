# M19 模型与执行路由（审计定稿）

> **版本**：v1.0（2026-11-18）  
> **状态**：定稿，待实现（**独立于 M18**）  
> **上游**：`doc/milestones/M6-Bot工厂.md`（全局单 Key 基线）、`doc/milestones/M18-业务插件需求规格.md` §9、`AGENTS.md`

M19 交付 **LLM 端点** 与 **Agent 探针** 的复杂路由，不阻塞 M18 业务插件竖切。未安装本里程碑插件时，行为与 M6「全局单 API Key」默认一致。

---

## 1. 目标与非目标

### 1.1 目标

1. 按 `bot_id`、`channel`、`msg_type`、工具提示等规则，将 Bot **推理请求** 路由到不同 LLM 端点（含 fallback、熔断、配额计数）。
2. 在 Bot 已声明的 `allowed_agents` 内，按规则选择 **本地 vs 远程** 探针（不扩大 ACL）。
3. 每次路由决策可审计（轨迹摘要），原始大 payload 不进 Bot 单体记忆全文。
4. API Key 与端点凭据仅 **`secret_ref`**；规则表存在插件自有存储，**不进** `kernel_config_*` 正文。

### 1.2 非目标

- 多 vendor 自动竞价、成本优化求解器。
- 将 MCP 服务器注册为「模型端点」。
- 修改 Ingress 信封 schema 或 hub Transport 帧格式。
- 在内核实现路由逻辑。

## 2. 插件标识

| 字段 | 值 |
| --- | --- |
| `plugin_id` | `plugin_model_router` |
| `plugin_type` | `executor` |
| `plugin_category` | `foundation`（可选安装；未安装则走 M6 默认） |
| Owner Bot | `router_bot` |
| 自有 schema | `model_router`（示例名） |
| `deps` | `plugin_tool_center`（轨迹与授权对齐） |

**配置中心**：`global` 域仅允许指针型字段，例如 `default_llm_endpoint_ref`、`router_plugin_id=plugin_model_router`；**不存** 规则 JSON 或明文 Key。

## 3. 功能需求

| ID | 描述 | 优先级 |
| --- | --- | --- |
| REQ-RT-F01 | 插件表 `match_rules` → `endpoint_ref` / `agent_id` | P0 |
| REQ-RT-F02 | L2 sidecar：统一出站 LLM 调用，解析 `secret_ref` | P0 |
| REQ-RT-F03 | 主端点失败 → 可配置 fallback 一次 → 结构化错误 | P0 |
| REQ-RT-F04 | Agent 路由仅在 `allowed_agents` 内生效 | P1 |
| REQ-RT-F05 | 轨迹：bot、规则 id、选中端点/探针、耗时、结果码 | P0 |
| REQ-RT-F06 | 规则变更 Tier 2：`config propose` + `user_bot` 或插件配置审批流 | P0 |
| REQ-RT-F07 | Bot **不得**自改路由表 | P0 |

### 3.1 与 M6 共存

| 状态 | Bot 推理行为 |
| --- | --- |
| 未安装 `plugin_model_router` | 使用 `global` 单 Key 与默认端点（M6） |
| 已安装且规则命中 | sidecar 按规则选端点 |
| 已安装无匹配规则 | 回退 M6 默认（可配置是否严格拒绝） |

## 4. 架构审计

| 检查项 | 结论 |
| --- | --- |
| 路由逻辑不进 hub | 必须 |
| Bot 禁 Shell；sidecar 不发 OS 命令 | 必须 |
| 探针选择不绕过 agent mesh ACL | 必须 |
| MCP/Skill 不进配置中心 | 必须 |
| 密钥不进清单/manifest 明文 | 必须 |
