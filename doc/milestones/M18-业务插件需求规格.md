## 3. `plugin_pm` — 项目管理插件

### 3.1 清单标识

| 字段 | 值 |
| --- | --- |
| `plugin_id` | **`plugin_pm`** |
| `plugin_type` | `workspace` |
| `plugin_category` | `business` |
| Owner / 业务 Bot | `pm_bot`（可兼 owner 与业务 NL） |
| 自有 schema | `pm` |
| `deps` | `plugin_groupchat`、`plugin_bot_creator`、`plugin_tool_center` |

### 3.2 数据模型（PM 自有表，不入 `kernel`）

```text
pm_projects
  project_id        TEXT PK     # 建议前缀 proj_，用户可读
  root_path         TEXT        # 宿主机绝对路径，激活前 user_bot 批准
  display_name      TEXT
  status            TEXT        # active | archived
  created_at        TIMESTAMPTZ

pm_project_members
  project_id        TEXT FK
  bot_id            TEXT        # 全局唯一 bot_id
  role              TEXT        # owner | dev | qa | ...

pm_project_rooms
  project_id        TEXT FK
  room_id           TEXT        # 对接 groupchat 房间 ID

pm_tasks                          # 看板/任务（MVP 字段集）
  task_id, project_id, column_id, title, description, status, ...
```

**事件（示例）**：`plugin_pm.project.activated`、`plugin_pm.task.state_changed`（持久事件，走 Outbox）。

**不实现**：在内核 `kernel_projects` 落业务字段；不向 PM schema 复制 `MEMORY.md` 正文。

### 3.3 项目记忆与 `.bots`（Q1）

#### 3.3.1 路径约定

```text
{root_path}/
  ... 用户工程文件 ...
  .bots/
    <bot_id>/
      memory/
        MEMORY.md              # ≤200 行（与单体栈一致）
        transcripts/...
        notes/...
        representations/...
```

#### 3.3.2 读写边界

| 主体 | 对 `{root}/.bots/**` | 对 `{root}/**/*.md` 等项目文件 |
| --- | --- | --- |
| `plugin_pm` L2 | **只读**（扫描、列表、预览） | **只读索引 + 查询 API** |
| 浏览器 / VS Code Ingress | 不直接读盘；上下文经用户附加或 Bot 工具 | 同左 |
| `bot-runtime` | **读写**（经批准的 `memory_root`） | 不默认写 |
| 用户 Save & Restart / 编辑器 | 读写 | 读写 |

**铁律**：PM 源码与测试 **不得** 含对 `.bots` 的写操作；CI 可加静态检查。

#### 3.3.3 项目记忆（无 `plugin_memory` 阶段）

- **项目文档**：PM 对 `root_path` 下可配置 glob（默认 `**/*.md`，排除 `.bots/**`）维护 **只读索引**（路径、mtime、size），供工作台搜索与 `@bot` 上下文引用。
- **项目内 Bot 记忆**：展示来源于 `.bots/<bot_id>/` 扫描；编辑走 Bot 工厂 / 群聊 **Save & Restart**，不经 PM 写盘。
- **`plugin_memory` 定稿后**：通过新版本依赖与迁移，将索引升级为图谱引用；**不改变** `.bots` 只读边界与方案 A 路径约定。

#### 3.3.4 方案 A：记忆根绑定（已确认）

1. 用户在项目内为 Bot 配置 `memory_root = {root_path}/.bots/{bot_id}`。
2. 写入路径：`scope_type=bot`，走配置中心 **propose → security → user_bot approve → activate**，**Restart Policy** 生效。
3. PM 激活 `root_path` 时重扫 `.bots/`，与 `pm_project_members` 对齐；**禁止** PM 自动改写 bot 配置中的 `memory_root`。
4. **全局唯一 `bot_id`**：一个 Bot 只属于一个 `project_id`（多项目场景使用 `user_<proj>_reviewer_bot` 等派生命名）。

### 3.4 功能需求

| ID | 描述 | 优先级 |
| --- | --- | --- |
| REQ-PM-F01 | 项目 CRUD；`root_path` Tier 2 批准 | P0 |
| REQ-PM-F02 | `.bots` 只读扫描、Bot 列表与 `MEMORY.md` 预览 | P0 |
| REQ-PM-F03 | 项目群聊房间（groupchat-core）；`Room.Metadata.project_id` | P0 |
| REQ-PM-F04 | 项目 Bot 编制（bot_factory 提案 + `user_bot`） | P0 |
| REQ-PM-F05 | 看板/任务 + `plugin_pm.task.state_changed` | P0 |
| REQ-PM-F06 | 任务卡发起用户身份 `@` 研讨 | P1 |
| REQ-PM-F07 | 声明 `deps` SemVer，DAG 深度 ≤ 2 | P0 |

### 3.5 验收

- [ ] `root_path` 批准后列出 `.bots` 与子 Bot、`MEMORY.md` 只读预览正确。
- [ ] grep/审计：PM 无 `.bots` 写路径。
- [ ] Bot Save & Restart 后 PM 重扫可见变更（不经 PM 写盘）。
- [ ] 用户 `@` 唤醒；Bot 回复内 `@` 不投递。
- [ ] 卸载被依赖时 409；`--cascade` 逆拓扑停机。

## 4. `plugin_browser` — 浏览器 Ingress（首期）

### 4.1 清单标识

| 字段 | 值 |
| --- | --- |
| `plugin_id` | `plugin_browser` |
| `plugin_type` | `ingress` |
| `plugin_category` | `business` |
| `deps` | `plugin_tool_center`；可选 `plugin_groupchat` |

### 4.2 范围

**包含**：Chromium 系扩展；选区/URL/`@bot_id`；本地 token 连 L2；Ingress **`from_bot_id=user_bot`**，`channel=web`；站点 allowlist；密码框不采集；浮层展示回复与轨迹摘要。

**不包含（后期 `plugin_browser_ctl` 等）**：无头浏览器、全量 DOM、`browser.evaluate`、页面自动化。

### 4.3 功能需求

| ID | 描述 | 优先级 |
| --- | --- | --- |
| REQ-BR-F01 | 扩展解析 `@<bot_id>`，校验 Hub 同步列表 | P0 |
| REQ-BR-F02 | L2 封装 Ingress，**仅 user_bot 委托** | P0 |
| REQ-BR-F03 | ContextEnvelope：`page_url`、`title`、`selection_text`（无 `password` 字段） | P0 |
| REQ-BR-F04 | 站点 allowlist；非 allowlist 拒绝并提示 | P0 |
| REQ-BR-F05 | 浮层流式回复 + 轨迹摘要 | P0 |

### 4.4 验收

- [ ] allowlist 内 `@user_writer_bot` 浮层回复，因果链完整。
- [ ] 非 allowlist 拒绝。
- [ ] 无 user_bot 委托的投递路径不存在。
- [ ] `plugin stop plugin_browser` 扩展降级行为明确。

| ID | 描述 | 优先级 |

| REQ-OBS-F01 | `plugin_obsidian.query_files`：root + pattern → 路径列表 | P0 |
| REQ-OBS-F02 | `plugin_obsidian.read_file`：大小上限、拒绝二进制、拒绝 path traversal | P0 |
| REQ-OBS-F03 | Bot 经 tool_grants 调用；默认无网 | P0 |
| REQ-OBS-F04 | `@bot` 附 `vault_root` + `relative_path` 于 ContextEnvelope | P0 |

### 5.3 非目标

- Vault 一键导入、wikilink 图谱、`memory_embeddings`、审核写入弹窗 → 待 `plugin_memory` 定稿后另里程碑。

### 5.4 验收

- [ ] 授权 Bot 查询/读取允许目录成功；越界路径拒绝并记轨迹。
- [ ] 未授权 Bot 调用拒绝。
